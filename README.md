## 💻 Local Preview

You can open `index.html` directly in any web browser, or serve it locally with Node.js:

```bash
# Using the bundled Node.js server
node server.js
```

Then open `http://localhost:3000/`.

## 🌐 Free Deployment Options

### 1. Vercel
Simply push to GitHub and import the repository on [Vercel](https://vercel.com). It will deploy automatically with zero configuration.

### 2. GitHub Pages
1. Go to repository **Settings** > **Pages**.
2. Select the `main` branch and `/ (root)` folder.
3. Save, and your portfolio will be live at `https://<your-username>.github.io/<repo-name>/`.
